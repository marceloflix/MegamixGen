# MegamixGen 🎵

A high-performance DJ tracklist and harmonic megamix generator with Serato-compatible Camelot harmonic wheel matching, intelligent BPM transition sorting, and authoritative musical key detection.

## Features
- **Zero-Guessing Harmonic Wheel**: Serato Camelot system (`1A`-`12B`) and Open Key matching.
- **Authoritative BPM & Musical Key**: Powered by direct musical database integration.
- **Intelligent Transitions**: Automatic sorting by Camelot energy ramp, BPM proximity, or energy flow.
- **Offline Caching**: All verified song BPMs and keys are cached locally in your browser to minimize API calls.

## Attribution & Data Source
